# Security Policy

## Reporting a Vulnerability

If you noticed a vulnerability or any kind of security breach, please report it in the [**issues**](https://github.com/Casen9/CalculatorTkinter/issues).

> [!IMPORTANT]
> **Do not report the fact that this program is getting flagged by an antivirus or Windows' Smart App Control.**<br>
> I can't do anything about it yet. Those issues will be closed.
